# 模块 03：公司财务报表深度分析与估值建模 (Fundamental Analysis & Valuation)

## 模块导读
“买股票就是买公司的一部分。” 长期来看，股票价格的最终锚定点必然回归公司的内在价值创造与现金流贴现能力。
靠小道消息和短线博弈难以跨越牛熊周期，唯有掌握严谨的财务报表解剖能力、法务会计防暴雷技能、商业护城河量化模型与 DCF/相对估值建模，才能在市场发生极端恐慌时，拥有“在别人贪婪时我恐惧，在别人恐惧时我贪婪”的底层定价底气。
