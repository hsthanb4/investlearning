# 📊 职业交易员与投资人能力评估雷达矩阵 (Trader Competency Framework)

从散户噪音交易者（Noise Trader）跃迁至顶级对冲基金投资总监（CIO），需要经历 5 个阶梯式的认知与技能迭代：

```
+----------------------------------------------------------------------------------------------------+

+-----------------+----------------------------------------+---------------------------+-------------------------+
| Level 1: 噪音客 | 追涨杀跌，看股吧新闻与大V荐股；        | 缺乏期望值与概率思维；    | 07_psychology_execution |

|                 | 重仓单只股票，无止损纪律。             | 资本，容易在极端行情爆仓。|                         |
+-----------------+----------------------------------------+---------------------------+-------------------------+
| Level 2: 图表客 | 沉迷技术指标（KDJ/MACD金叉死叉）；     | 把滞后指标当神谕；        | 04_technical_pa         |
| (Chart Trader)  | 能看懂支撑阻力与基础形态；             | 缺乏微观订单流与流动性认知| 02_micro_market         |

+-----------------+----------------------------------------+---------------------------+-------------------------+

| (Portfolio CIO) | 运用全天候风险平价与杠铃对冲策略；     | 唯一对手是不可预测的宏观  | 09_special_situations   |
|                 | 追求高夏普比率（Sharpe > 2.0）与大容量。| 地缘大变局与系统性流动性危机| 10_system_infra      |
```
