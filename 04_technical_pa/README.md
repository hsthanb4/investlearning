# 模块 04：价格行为学、趋势跟踪与技术形态论 (Technical Analysis & Price Action)

## 模块导读
“在交易的世界里，图表反映的不是未来，而是所有市场参与者基于恐惧、贪婪与流动性诉求所作出的全部集体行为的微观轨迹。” —— 约翰·墨菲（John Murphy）

传统散户技术分析往往沦为“看图说话”、“马后炮划线”甚至是充斥宿命论的玄学：
- 看到均线金叉就盲目追涨，却陷入震荡市中被反复左右抽耳光的无休止止损；
- 痴迷于“神仙指标”的调参过拟合，对“前视偏差（Look-Ahead Bias）”和“交易费用滑点”毫无量化认知；
- 孤立地观察头肩顶、双重底等几何形态，却不知绝大多数形态在随机游走（Random Walk）序列中同样高频出现，缺乏严格的统计检验与期望值验证；
- 忽视机构“流动性获取（Liquidity Hunting）”与大单执行的微观机制，在虚假突破（Liquidity Sweep）的高潮中屡屡成为机构主力派发或吸筹的牺牲品。

现代量化技术分析与价格行为学（Price Action）的统计本质是：**在非完全有效市场（Weak-Form Inefficient Market）中，通过微观供需不平衡、市场结构演变（Market Structure）、主力订单沉淀区（Order Blocks）以及多周期动量与波动率的非对称压缩释放，捕捉具备统计显著性的正期望值（Positive Expected Value）交易边缘（Edge）。**

本模块立足职业交易员与量化高频/日内/CTA 对冲基金的核心投研框架，剥离一切主观臆断与过拟合神话，从**摆动高低点识别与市场结构突破状态机（BOS / CHoCH）**、**机构供需区（Order Blocks）与假突破流动性扫荡（Liquidity Sweep）检测**、**经典几何形态（头肩底）的严密数学拓扑提取与假突破过滤**、**无前视偏差向量化动量与自适应波动率通道**，到**筹码成交量分布（Volume Profile, POC/VAH/VAL）与日内 VWAP 偏离对冲策略**，建立一套客观、可证伪、抗噪性极强的专业价格行为量化体系。
