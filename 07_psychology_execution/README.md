# 模块 07：行为金融学、交易心理与执行纪律 (Behavioral Finance & Psychology)

## 模块导读
“市场是人性弱点的放大器，交易最终修的是自己的心性。”
散户亏损的根源往往不是数学或智商不如机构，而是进化生物学遗留在大脑中的认知偏差——害怕亏损却在亏损时死扛、赚了一点就急于落袋为安、连续亏损后报复性重仓开仓。
本模块从卡尼曼（Daniel Kahneman）前景理论（Prospect Theory）与处置效应（Disposition Effect）切入，建立职业交易员的执行清单机制、不可变止损纪律、数字复盘日志与贝叶斯归因模型，帮你在充满贪婪与恐惧的博弈场中建立机器般冷酷的执行护城河。
