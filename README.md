## 使用方式

1. 按模块内编号循序渐进学习，一次只做一课。
2. 每课提交唯一代码填空题、运行输出和 Q1～Q3 思考题回答；环境不可用时明确写“静态审查，运行待验证”。
3. 评分为代码 4 分、三个问答各 2 分；达到 8/10 且无关键误解才算通过。
4. `main` 永远只保留题目练习版；`answers/` 目录或分支才包含标准参考答案。不要在第一次独立尝试前查看参考答案。


## 🎨 视觉与排版美学规范 (Anthropic-Style & Quarto Publication Standards)

全套课程与在线交互平台严格遵循以下三项统一出版美学规范：
1. **语言调性（冷静、第一性原理）**：
   - 保持资深投资机构投决会（Investment Committee）的专业克制语气，严禁口号、鸡汤或虚无预测；
   - 所有论述围绕商业本质、财务会计守恒、资本回报率（ROIC）与风险定价展开；
   - 所有段落杜绝大块文本墙，必须采用“- **[核心标签]**：论述内容”的结构展开。
2. **图文并茂与就近排版（视线即达）**：
   - 每一课标配 2~3 张图（概念架构图、分析曲线图或 Mermaid 决策流）；
   - 严禁在章节开头集中堆砌图片，图片必须遵循“引导句锚点 -> 紧随图片容器卡片 -> 紧随 1/2/3 要点拆解”的三位一体排版，确保指引与图像在同一视口内呈现。
3. **视觉与排版美学（Anthropic 极简风）**：
   - 图表使用低饱和度、温暖素雅的石墨黑（#1F1E1B）、陶土褐（#CC5A36）、冷杉绿（#5F7355）与灰钴蓝（#486A7D）调色板，严禁刺眼的高饱和对比色；

## 推荐学习顺序

1. **第一阶段（认清市场物理现实）**：`01_macro_cycle`（第 1~3 课） → `02_micro_market`（限价订单簿与交易规则）
2. **第二阶段（建立价值与价格基准）**：`03_fundamental`（财报勾稽与估值建模） → `04_technical_pa`（价格行为与供需区）
3. **第三阶段（科学工程化与风控护城河）**：`06_risk_portfolio`（仓位管理与凯利公式） → `05_quant_trading`（多因子与统计套利）
4. **第四阶段（高维武器与绝对收益）**：`08_derivatives_hedge`（期权对冲） → `09_special_situations`（转债与事件套利）
5. **第五阶段（操盘心性与实盘系统落地）**：`07_psychology_execution`（克服人性偏差） → `10_system_infra`（搭建实盘风控系统）
